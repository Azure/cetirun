# CetiRun support

## Get help or report a problem

Use [GitHub Issues](https://github.com/Azure/cetirun/issues) for CetiRun bugs,
feature requests, and questions. Search existing issues and the
[project documentation](README.md) first, then choose the matching
[issue form](https://github.com/Azure/cetirun/issues/new/choose).

For a useful report, include:

- the affected component and runtime, if relevant;
- the CetiRun commit, image tag or digest, and chart version you used;
- expected and actual behavior, with the smallest reproduction you can share;
- relevant OS, architecture, Kubernetes, Helm, Go, or Node.js versions; and
- a short, sanitized output excerpt and any workaround you have tried.

Do not upload credentials, cookies, kubeconfigs, private endpoints, tenant or
subscription identifiers, customer data, agent conversations, or internal logs.
Use synthetic examples and follow the
[public-data guidance](CONTRIBUTING.md#keep-contributions-safe-to-publish).
Do not grant anyone access to your environment just to file a report.

## Security and conduct

Report suspected security vulnerabilities privately to the Microsoft Security
Response Center (MSRC), following [SECURITY.md](SECURITY.md). GitHub Issues and
pull requests are not the reporting channel for vulnerabilities.

For conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), which
includes the Microsoft Open Source Code of Conduct contact information.

## Maintenance and support expectations

Maintainers triage reports and review contributions on a best-effort basis.
Priority depends on impact, reproducibility, project direction, and available
maintainer time. A report may need more information before work can begin.

This repository does not promise a response time, resolution time, release
schedule, long-term support window, or backports to every version. Include the
version you use so maintainers can discuss whether a fix, an update, or a
workaround is appropriate. See [GOVERNANCE.md](GOVERNANCE.md) for maintainer
responsibilities.

Support for this open-source project is limited to the resources listed here.
An issue in this repository is not a Microsoft Azure support ticket and does
not create a commercial support agreement. Problems with an underlying cloud
service or a third-party agent may need that provider's support channel.
