CetiRun is an open-source managed runtime for hosting AI agents and AI applications.

CetiRun runs **OpenClaw and Hermes** on a shared AKS cluster.
A Kubernetes operator manages instances; a self-service portal lets users create
and access them. The runtime chart supports these two agent types.

Start with the [overview](overview/), [core concepts](concepts/), or
[architecture](concepts/architecture/). Read
[Security](security/) before granting access.
