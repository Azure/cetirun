CetiRun is an open-source managed runtime for hosting AI agents and AI applications.

An **Agent** is a long-lived workspace using OpenClaw or Hermes.
An **instance** is a deployed Agent workspace.
A **Team** supplies shared context and defaults; it is not a membership
or authorization policy. A **deployment** combines the operator, portal,
infrastructure, and policies that make those workspaces available to users.

Read [Architecture](architecture/) for component responsibilities and
[Security](../security/) for access controls and data protection.
