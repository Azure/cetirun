An Agent is your own long-lived AI agent. It keeps your files in a private,
persistent HOME volume. Before you create an Agent, ask your platform
administrator for the Portal address and access.

| Start here | What you can do |
| --- | --- |
| [Get Started](../getting-started/) | Create your first Agent and open it |
| [Using agents](../guides/) | Choose a model and manage the lifecycle of an Agent |
| [Agent Connections and Identity](../guides/agent-identity/) | Connect your GitHub, Google, or Azure access to an Agent |
| [Shared GitHub App](../guides/github-app/) | Give an Agent access to selected GitHub repositories |
| [Chat with a Custom Agent](../guides/custom-chat/) | Chat with a Custom Agent in the Portal |
| [Tour the portal](../guides/portal/) | Find the parts of the portal and the Agent page |
| [Troubleshoot your Agent](../guides/troubleshooting/) | Find the cause of common problems and the default limits |
| [Frequently asked questions](../guides/faq/) | Get short answers about files, models, privacy, and limits |

[connect Tailscale](../guides/tailscale/) to reach an Agent from your tailnet.
