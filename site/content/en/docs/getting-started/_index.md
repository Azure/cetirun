Choose where to start:

- **Use a deployment that already exists:** Ask your platform administrator for
  the Portal address and access. Then
  [create your first Agent](first-instance/). To choose a model and manage the
  Agent, use the [agent guides](../guides/).
- **Evaluate CetiRun:** Read the [Overview](../overview/), the
  [Architecture](../concepts/architecture/), and [Security](../security/).
- **Install CetiRun:** Prepare AKS and Microsoft Entra ID. Then follow
  [Install CetiRun](platform/) in Operations.
- **Run your own agent image:** Package the image as a Custom Agent that
  follows the [Agent Harness](../reference/agent-harness/) contract. The
  [examples]({{< repo "examples" "tree" >}}) show complete Custom Agents.
- **Use only the AI Gateway:** Install the AI Gateway chart for agents that you
  already run. [Install CetiRun](platform/) tells you how to install the
  component charts directly.
- **Develop or test CetiRun:** Follow
  [Prepare a development environment](../contributing/development/).
