Existing agents. Shared controls.

Native agents.
Shared platform controls.

CetiRun runs agents that already exist, for example OpenClaw and Hermes, and your own agent images. It does not add a new reasoning framework.

OAuth2 Proxy signs users in with Microsoft Entra ID, and the ingress gateway lets only the owner open an Agent. CetiAdmin, an operations Agent that the operator installs by default, helps platform administrators diagnose and repair Agents.

Isolation depends on the RuntimeClass, the network policies, and the Sandbox of each Agent. Read about workload isolation.
