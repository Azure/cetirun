Native agents.
Shared platform controls.

CetiRun runs agents that already exist, for example OpenClaw and Hermes, and your own agent images. It does not add a new reasoning framework.

OAuth2 Proxy signs users in with Microsoft Entra ID. When each user has a unique alias, the ingress gateway lets only the owner open an Agent. CetiAdmin, an operations Agent that the operator installs by default, can read the Secrets of each standard Agent and run commands in its Pod.

Isolation depends on the RuntimeClass, the network policies, and the Sandbox of each Agent. Read about workload isolation.

Understand the architecture

  • Deploy

    A namespace and a persistent HOME for each Agent, managed by the operator

  • Govern

    AI Gateway keys, budgets, and routing for every Agent, and Agent Policies and Sandboxes for the Agents of policy-bound Teams

  • Connect

    The Agent UI, chat, terminal, and desktop of each Agent, from a self-service Portal
